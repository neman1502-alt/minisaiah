# 🌟 성경분석 올인원 마스터 공유 허브 & 실시간 AI 분석 플랫폼

본 디렉토리(`d:\AI실습\1_성경분석\공유사이트`)는 지금까지 제작된 올인원 마스터 대통합 연구보고서를 타인에게 공유하고, **원격 사용자가 원하는 임의의 성경구절을 입력하면 9대 표준 규격(원어음독, D드라이브 주석/목성연 고찰, 4대 모형론, 6대 다학제 팩트체크, 공인통계, 강해설교문 등)으로 실시간 자동 생성·제공하는 통합 웹 플랫폼**입니다.

---

## 🚀 1. 주요 기능

1. **성경 66권 정경 순서 아카이브:**
   - 레위기, 민수기, 시편, 다니엘, 마태복음, 요한복음, 로마서 등 생성된 모든 마스터 보고서가 창세기 ~ 요한계시록의 정경 순서대로 자동 정렬되어 표시됩니다.
2. **⚡ 실시간 성경구절 AI 분석 요청기:**
   - 타인이 웹 브라우저에서 원하는 구절(예: `로마서 8:1-11`, `창세기 1:1-5`, `출애굽기 3:1-14`, `시편 23:1-6` 등)을 입력하고 버튼을 누르면, 백엔드 서버가 실시간으로 9대 올인원 마스터 규격 보고서를 생성하고 즉시 웹 열람 및 PDF/MD 다운로드를 제공합니다.
3. **영구 누적 및 자동 동기화:**
   - 실시간으로 생성된 새 보고서는 대시보드 목록(`reports_data.json`)에 정경 순서대로 자동 영구 등록됩니다.

---

## 🏃 2. 실행 방법

1. **원클릭 실행:**
   - `d:\AI실습\1_성경분석\공유사이트\원클릭_공유링크_실행.bat` (또는 프로젝트 루트의 `원클릭_공유링크_실행.bat`)를 더블클릭하여 실행합니다.
2. **공유 링크 복사:**
   - 실행 시 Cloudflare 터널을 통해 발급된 `https://xxxx.trycloudflare.com` 링크가 클립보드에 자동 복사되며, `실시간_공유링크.txt`에도 저장됩니다.
3. **타인 공유:**
   - 카카오톡, 문자, 이메일 등으로 링크를 전송하면 상대방이 스마트폰, 태블릿, PC 어디서든 즉시 접속하여 열람 및 실시간 분석을 이용할 수 있습니다.
